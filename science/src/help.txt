[FORTH]
SCIENCE ( -- ) The word list of the FV- and MAT- words for float vectors, matrices, linear algebra, special functions, integration and differential equations. ALSO SCIENCE adds it to the search order.
[SCIENCE]
FV-NEW ( n -- a ) A vector of n floats, all zero, on the heap; the program FREEs it. Elements are read and written with FV[] and F@ F!. ;; ALSO SCIENCE 3 FV-NEW FV-LEN . PREVIOUS => 3
FV-FROM-STACK ( n -- a ) ( F: x1 ... xn -- ) A vector of the n floats on the float stack. ;; ALSO SCIENCE 5e 7e 2 FV-FROM-STACK 1 SWAP FV[] F@ F>S . PREVIOUS => 7
FV-LEN ( a -- n ) The number of elements of a vector.
FV[] ( i a -- f-addr ) The address of element i (counted from 0) of a vector, for F@ and F!; -24 when i is out of range. ;; ALSO SCIENCE 3 FV-NEW DUP 2e 1 ROT FV[] F! 1 SWAP FV[] F@ F>S . PREVIOUS => 2
FV-FILL ( a -- ) ( F: x -- ) Set every element of the vector to x.
FV-DOT ( a b -- ) ( F: -- r ) The dot product of two vectors of one length. ;; ALSO SCIENCE 2e 3e 2 FV-FROM-STACK 1e 4e 2 FV-FROM-STACK FV-DOT F>S . PREVIOUS => 14
FV-NORM ( a -- ) ( F: -- r ) The Euclidean length of a vector.
FV-SCALE ( a -- c ) ( F: x -- ) A new vector: every element times x.
FV+ ( a b -- c ) A new vector: the sum of two vectors of one length.
FV- ( a b -- c ) A new vector: the difference of two vectors of one length.
MAT-NEW ( rows cols -- a ) A matrix of zeros on the heap; the program FREEs it. Stored a row after a row.
MAT-FROM-STACK ( rows cols -- a ) ( F: x11 x12 ... -- ) A matrix of the floats on the float stack, a row after a row. ;; ALSO SCIENCE 1e 2e 3e 4e 2 2 MAT-FROM-STACK MAT-DET F>S . PREVIOUS => -2
MAT-IDENTITY ( n -- a ) The n by n identity matrix.
MAT-HILBERT ( n -- a ) The n by n Hilbert matrix, with 1/(i+j+1) in row i and column j (from 0), a standard test of conditioning.
MAT-ROWS ( a -- n ) The number of rows of a matrix.
MAT-COLS ( a -- n ) The number of columns of a matrix.
MAT[] ( i j a -- f-addr ) The address of the element in row i and column j (from 0), for F@ and F!; -24 when one is out of range.
MAT-T ( a -- c ) A new matrix: the transpose.
MAT+ ( a b -- c ) A new matrix: the sum of two matrices of one shape.
MAT- ( a b -- c ) A new matrix: the difference of two matrices of one shape.
MAT-SCALE ( a -- c ) ( F: x -- ) A new matrix: every element times x.
MAT* ( a b -- c ) A new matrix: the product; the columns of a must equal the rows of b.
MAT*V ( a v -- w ) A new vector: a matrix times a vector.
MAT-NORM ( a -- ) ( F: -- r ) The infinity norm: the largest sum of the absolute values in a row.
MAT-LU ( a -- lu piv sign ) LU factorization with partial pivoting of a square matrix: lu holds L (unit diagonal, not stored) and U, piv is a vector with the original row of each row, sign is 1 or -1. Throws -264 when the matrix is singular.
LU-SOLVE ( b lu piv -- x ) Solve A x = b with the factorization of A that MAT-LU gave; cheap for many b.
MAT-SOLVE ( b a -- x ) Solve A x = b for a vector b, with an LU factorization. Throws -264 when A is singular. ;; ALSO SCIENCE 8e -11e -3e 3 FV-FROM-STACK 2e 1e -1e -3e -1e 2e -2e 1e 2e 3 3 MAT-FROM-STACK MAT-SOLVE 0 SWAP FV[] F@ F>S . PREVIOUS => 2
MAT-DET ( a -- ) ( F: -- r ) The determinant of a square matrix; 0 when it is singular.
MAT-INV ( a -- c ) The inverse of a square matrix, by Gauss-Jordan elimination. Throws -264 when it is singular.
MAT-COND ( a -- ) ( F: -- r ) The condition number in the infinity norm: the norm of A times the norm of its inverse.
MAT-GAUSS-JORDAN ( a b -- x ) Solve A X = B by Gauss-Jordan elimination, for a matrix B with a column for each right-hand side.
GAMMA ( F: x -- r ) The gamma function, with GAMMA(n) = (n-1)! at whole n. Throws -46 at 0 and the negative whole numbers, -43 above 171.6. ;; ALSO SCIENCE 5e GAMMA F>S . PREVIOUS => 24
LNGAMMA ( F: x -- r ) The natural logarithm of the absolute value of the gamma function; it does not overflow where GAMMA does. Throws -46 at 0 and the negative whole numbers. ;; ALSO SCIENCE 1000e LNGAMMA F>S . PREVIOUS => 5905
FACTORIAL ( n -- ) ( F: -- r ) The factorial n! as a float, for n from 0 to 170; throws -24 for a negative n, -43 above 170. ;; ALSO SCIENCE 10 FACTORIAL F>S . PREVIOUS => 3628800
ERF ( F: x -- r ) The error function, 2/sqrt(pi) times the integral of e^(-t^2) from 0 to x. ;; ALSO SCIENCE 1e ERF 1e6 F* F>S . PREVIOUS => 842700
ERFC ( F: x -- r ) The complementary error function, 1 - erf(x), accurate for a large x where 1 - ERF would lose all digits. ;; ALSO SCIENCE 1e ERFC 1e6 F* F>S . PREVIOUS => 157299
GAMMA-P ( F: a x -- r ) The regularized incomplete gamma function P(a, x), for a > 0 and x >= 0: the chance that a gamma variable with shape a is at most x. ;; ALSO SCIENCE 1e 1e GAMMA-P 1e6 F* F>S . PREVIOUS => 632120
GAMMA-Q ( F: a x -- r ) The complement 1 - P(a, x) of GAMMA-P, accurate in the tail. ;; ALSO SCIENCE 1e 1e GAMMA-Q 1e6 F* F>S . PREVIOUS => 367879
BETA ( F: a b -- r ) The beta function Gamma(a) Gamma(b) / Gamma(a + b), for a and b above 0. ;; ALSO SCIENCE 2e 3e BETA 1e3 F* F>S . PREVIOUS => 83
BETA-I ( F: a b x -- r ) The regularized incomplete beta function I(x; a, b) for a, b > 0 and x from 0 to 1: the cumulative distribution of the beta distribution. ;; ALSO SCIENCE 2e 3e 0.5e BETA-I 1e3 F* F>S . PREVIOUS => 687
LOGISTIC ( F: x -- r ) The logistic function 1 / (1 + e^-x); no overflow for any x. ;; ALSO SCIENCE 0e LOGISTIC 10e F* F>S . PREVIOUS => 5
LOGISTIC-D ( F: x -- r ) The derivative of the logistic function, s (1 - s) with s = LOGISTIC(x). ;; ALSO SCIENCE 0e LOGISTIC-D 100e F* F>S . PREVIOUS => 25
TRAPEZOID ( xt n -- ) ( F: a b -- r ) The integral of the function xt, with the effect ( F: x -- y ), from a to b by the trapezoid rule with n panels; throws -24 when n is below 1. ;; ALSO SCIENCE -1e 1e ' FABS 2 TRAPEZOID F>S . PREVIOUS => 1
SIMPSON ( xt n -- ) ( F: a b -- r ) The integral of the function xt, with the effect ( F: x -- y ), from a to b by Simpson's rule with n panels (n is made even); exact for a cubic. Throws -24 when n is below 1. ;; ALSO SCIENCE 0e 1e ' FEXP 10 SIMPSON 1e6 F* F>S . PREVIOUS => 1718282
TRAPEZOID-TOL ( xt -- ) ( F: a b tol -- r err ) The integral of the function xt by the trapezoid rule, halving the panels until two sums differ by at most tol * max(1, |r|); leaves the result and that difference. Throws -264 after 20 halvings. ;; ALSO SCIENCE 0e 3.141592653589793e ' FSIN 1e-8 TRAPEZOID-TOL FDROP 1e3 F* 0.5e F+ F>S . PREVIOUS => 2000
ROMBERG ( xt -- ) ( F: a b tol -- r err ) The integral of the function xt by Romberg's method (the trapezoid rule with Richardson extrapolation), until two values differ by at most tol * max(1, |r|); leaves the result and that difference. Fast for a smooth function. Throws -264 after 20 halvings. ;; ALSO SCIENCE 0e 3.141592653589793e ' FSIN 1e-10 ROMBERG FDROP 1e3 F* 0.5e F+ F>S . PREVIOUS => 2000
INTEGRATE ( xt -- ) ( F: a b tol -- r err ) The integral of the function xt by adaptive Gauss-Legendre: it splits the interval with the largest error until the sum of the errors is at most tol * max(1, |r|). Leaves the result and the error estimate (the difference between one 5-point rule and two on the halves, usually far above the true error). Copes with a function that is not smooth; throws -264 after 500 intervals. ;; ALSO SCIENCE 0e 1e ' FSQRT 1e-8 INTEGRATE FDROP 1e6 F* 0.5e F+ F>S . PREVIOUS => 666667
RK4 ( y xt steps -- ) ( F: t0 t1 -- ) Solve y' = f(t, y) from t0 to t1 with the classical Runge-Kutta method of order 4 in a fixed number of steps. y is a float vector that changes in place; xt is a word with the effect ( y dy -- ) ( F: t -- ) that fills dy with the derivative. Throws -24 when steps is below 1. ;; ALSO SCIENCE : DECAY FDROP SWAP 0 SWAP FV[] F@ FNEGATE 0 SWAP FV[] F! ; 1e 1 FV-FROM-STACK DUP ' DECAY 10 0e 1e RK4 0 SWAP FV[] F@ 1e6 F* F>S . PREVIOUS => 367879
ODE-RKF ( y xt -- ) ( F: t0 t1 tol -- ) Solve y' = f(t, y) from t0 to t1 with the adaptive Runge-Kutta-Fehlberg method of orders 4 and 5: it chooses the steps so that the error of a step stays below tol * (1 + |y|) in each component. y is a float vector that changes in place; xt is a word with the effect ( y dy -- ) ( F: t -- ). t1 may be below t0. Throws -264 when the step gets too small or after 100000 steps. ;; ALSO SCIENCE : DECAY2 FDROP SWAP 0 SWAP FV[] F@ FNEGATE 0 SWAP FV[] F! ; 1e 1 FV-FROM-STACK DUP ' DECAY2 0e 1e 1e-9 ODE-RKF 0 SWAP FV[] F@ 1e6 F* F>S . PREVIOUS => 367879
(F<=) ( F: x y -- ) ( -- flag ) True when x <= y; false when one is NaN. A helper of the integration words.
(S!) ( i s -- ) ( F: x -- ) Store x in element i of the scratch vector s. A helper of the integration words.
(S@) ( i s -- ) ( F: -- x ) Fetch element i of the scratch vector s. A helper of the integration words.
(T0) ( xt s -- ) The first trapezoid sum, for the helpers of ROMBERG and TRAPEZOID-TOL.
(TNEXT) ( xt level s -- ) The trapezoid sum with the panels halved, for the helpers of ROMBERG and TRAPEZOID-TOL.
(CONVERGED?) ( k -- flag ) ( F: err r tol -- ) True when err <= tol * max(1, |r|) after 3 halvings; a helper of ROMBERG and TRAPEZOID-TOL.
(ROMBERG-ROW) ( k e s -- ) The next row of the Romberg table; a helper of ROMBERG.
(GL-X1) ( F: -- x ) The second node of the 5-point Gauss-Legendre rule; a helper of INTEGRATE.
(GL-X2) ( F: -- x ) The third node of the 5-point Gauss-Legendre rule; a helper of INTEGRATE.
(GL-W1) ( F: -- w ) The weight of the node GL-X1; a helper of INTEGRATE.
(GL-W2) ( F: -- w ) The weight of the node GL-X2; a helper of INTEGRATE.
(G5PAIR) ( xt v -- ) ( F: x w -- r ) The contribution of a pair of nodes to the 5-point rule; a helper of INTEGRATE.
(G5) ( xt -- ) ( F: a b -- r ) The integral over [a, b] by the 5-point Gauss-Legendre rule; a helper of INTEGRATE.
(INTERVALS) ( -- n ) The most intervals that INTEGRATE keeps, 500.
(ROW!) ( xt m r -- ) ( F: a b -- ) Evaluate an interval and store it in row r of the matrix m; a helper of INTEGRATE.
(COMB) ( n y ks tab r cols out -- ) ( F: h -- ) A linear combination of stage vectors; a helper of ODE-RKF.
(LC) ( y k out -- ) ( F: c -- ) out = y + c * k; a helper of RK4.
(TROW) ( m r -- ) ( F: x0 ... x5 -- ) Store six floats in row r of a matrix; a helper of ODE-RKF.
(RKF-TABLE) ( -- m ) The matrix of coefficients of Fehlberg's method; a helper of ODE-RKF.
(FACTOR) ( F: en -- f ) The factor for the next step of ODE-RKF, 0.9 en^-1/5 between 1/5 and 5.
(TOTALS) ( m n s -- ) Add up the integrals and the errors of the n intervals of m into the scratch vector s; a helper of INTEGRATE.
(WORST) ( m n s -- i ) The number of the interval with the largest error; a helper of INTEGRATE.
(ENOUGH?) ( s -- flag ) True when the error sum of INTEGRATE is within the tolerance; a helper of INTEGRATE.
