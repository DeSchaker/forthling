NELDER-MEAD ( x xt -- ) ( F: step tol -- fmin ) Minimize the function xt, with the effect ( v -- ) ( F: -- y ) for a vector v of n floats, by the Nelder-Mead simplex method, which needs no derivative. x is the start vector and changes in place to the best point; step is the size of the first simplex (each coordinate in turn is moved by it). Ends when the values at the points of the simplex differ by at most tol * (1 + |best|), so the point itself is good to about the square root of tol. Leaves the least value. Throws -264 for a NaN from the function or after 1000 n + 1000 steps, -24 when step is 0. ;; ALSO SCIENCE : BOWL 0 SWAP FV[] F@ 3e F- FDUP F* ; 0e 1 FV-FROM-STACK DUP 1e 1e-12 ' BOWL NELDER-MEAD FDROP 0 SWAP FV[] F@ 1e3 F* 0.5e F+ F>S . PREVIOUS => 3000
LM-FIT ( p xt m -- ) ( F: tol -- ssr ) Fit the parameters p, a float vector that changes in place, by Levenberg-Marquardt nonlinear least squares. xt has the effect ( p r -- ) and fills the vector r of m residuals (the model minus the data) for p; the Jacobian comes from central differences. Ends when a step lowers the sum of squares by at most tol times that sum, or when no damped step lowers it. Leaves the sum of squares. Throws -264 after 200 steps or for a NaN, -24 when m or p is empty. ;; ALSO SCIENCE : LMR {: p r :} 3 0 DO 0 p FV[] F@ I 1+ S>F F* I 1+ S>F 2e F* F- I r FV[] F! LM-COVARIANCE ( p xt m -- c ) The covariance matrix of the fitted parameters p for the residual word xt: (J^T J)^-1 times the sum of squares over (m - n), with the Jacobian J at p. The square roots of its diagonal are the standard errors. Needs m above the number of parameters (-24 otherwise); throws -264 when J^T J is singular, for example when a parameter does not change the residuals.

(NM-RANK) ( fv -- lo hi nx ) The indexes of the lowest, the highest and the second highest value. A helper of NELDER-MEAD.
(NM-CENTROID) ( m hi cv -- ) The centroid of all rows of the simplex but row hi, into cv. A helper of NELDER-MEAD.
(NM-TRY) ( m hi cv tv xt s -- ) ( F: -- f ) Put c + t (x_hi - c) in tv, with t in element 2 of the scratch vector s, and leave the function value there. A helper of NELDER-MEAD.
(NM-SHRINK) ( m lo fv tv xt -- ) Move every point of the simplex halfway to the best one and evaluate it again. A helper of NELDER-MEAD.
(LM-JAC) ( p xt jm rp rm sc -- ) The Jacobian at p by central differences, into jm. A helper of LM-FIT and LM-COVARIANCE.
(LM-STEP) ( a dg rhs s -- d ) Solve (A + lambda diag(A)) d = rhs for the Levenberg-Marquardt step. A helper of LM-FIT.
