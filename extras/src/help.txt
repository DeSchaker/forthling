// The help text of the word lists of forthling-extras, in the form of src/help.txt of forthling.
[FORTH]
CSV ( -- ) The word list of the CSV- words for comma-separated values. ALSO CSV adds it to the search order.
DATE ( -- ) The word list of the date and time words: ISO 8601, day of week and date arithmetic, on seconds since 1970 in UTC. ALSO DATE adds it to the search order.
ENCODING ( -- ) The word list of base64, hex, SHA-256 and CRC-32. ALSO ENCODING adds it to the search order.
URL ( -- ) The word list of percent-encoding and the words that split a URL into scheme, host, port, path, query and fragment. ALSO URL adds it to the search order.
UUID ( -- ) The word list of UUID4, a random version 4 UUID. ALSO UUID adds it to the search order.
[CSV]
CSV-SEPARATOR ( char -- ) The separator between fields; a comma to begin with. 9 gives tabs, 59 semicolons.
CSV-FIELD ( c-addr u -- rest-addr rest-u field-addr field-u last? ) The first field of the text without its quotes, and what is left; last? is true when the field ended its record. A doubled quote inside stays doubled (see CSV>STRING). ;; ALSO CSV S" ab,c" CSV-FIELD . TYPE 2DROP PREVIOUS => 0 ab
CSV-SKIP ( c-addr u -- rest-addr rest-u ) Skip one record, for a header line. ;; ALSO CSV S" a,b" CSV-SKIP NIP . PREVIOUS => 0
CSV>STRING ( c-addr u -- c-addr' u' ) A field with its doubled quotes made single. The new text is ALLOCATEd.
CSV-QUOTE ( c-addr u -- c-addr' u' ) A field as it is written: in quotes, with quotes doubled, when it holds the separator, a quote or a line end. The new text is ALLOCATEd.
[ENCODING]
>BASE64 ( c-addr u -- c-addr' u' ) The text as base64 (RFC 4648), padded with =. The new text is ALLOCATEd. ;; ALSO ENCODING S" foobar" >BASE64 TYPE PREVIOUS => Zm9vYmFy
BASE64> ( c-addr u -- c-addr' u' ) The bytes of padded base64 text; throws -265 for anything else. The new text is ALLOCATEd. ;; ALSO ENCODING S" Zm9vYg==" BASE64> TYPE PREVIOUS => foob
>BASE64URL ( c-addr u -- c-addr' u' ) The text as base64url (- and _ for + and /), without padding. The new text is ALLOCATEd. ;; ALSO ENCODING S" fo" >BASE64URL TYPE PREVIOUS => Zm8
BASE64URL> ( c-addr u -- c-addr' u' ) The bytes of base64url text, with or without padding; throws -265 for anything else. The new text is ALLOCATEd.
>HEX ( c-addr u -- c-addr' u' ) The bytes as two lower-case hex digits each. The new text is ALLOCATEd. ;; ALSO ENCODING S" Hi!" >HEX TYPE PREVIOUS => 486921
HEX> ( c-addr u -- c-addr' u' ) The bytes of hex text, upper or lower case; throws -265 for an odd length or a character that is not a digit. The new text is ALLOCATEd. ;; ALSO ENCODING S" 486921" HEX> TYPE PREVIOUS => Hi!
SHA-256 ( c-addr u -- c-addr' u' ) The SHA-256 digest of the text: 32 bytes (use >HEX to show them). The new text is ALLOCATEd. ;; ALSO ENCODING S" abc" SHA-256 >HEX TYPE PREVIOUS => ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
CRC-32 ( c-addr u -- u ) The CRC-32 checksum of the text, as in zip and PNG. ;; ALSO ENCODING S" 123456789" CRC-32 HEX . DECIMAL PREVIOUS => CBF43926
[DATE]
>ISO8601 ( seconds -- c-addr u ) The time as ISO 8601 text in UTC, like 2001-09-09T01:46:40Z. The text is ALLOCATEd. Throws -265 outside the years 0 to 9999. ;; ALSO DATE 1000000000 >ISO8601 TYPE PREVIOUS => 2001-09-09T01:46:40Z
ISO8601> ( c-addr u -- seconds ) Read YYYY-MM-DD (midnight) or YYYY-MM-DDTHH:MM:SS with Z, an offset like +02:00, or nothing (UTC). Throws -265 for anything else, also for a date that does not exist. ;; ALSO DATE S" 2001-09-09T03:46:40+02:00" ISO8601> . PREVIOUS => 1000000000
SECONDS>DATE ( seconds -- sec min hour day month year ) The parts of a time in UTC, in the order of TIME&DATE. ;; ALSO DATE 1000000000 SECONDS>DATE . . . . . . PREVIOUS => 2001 9 9 1 46 40
DATE>SECONDS ( sec min hour day month year -- seconds ) The time of the parts, in the order of TIME&DATE, so TIME&DATE DATE>SECONDS is now. Throws -265 for a date or time that does not exist. ;; ALSO DATE 40 46 1 9 9 2001 DATE>SECONDS . PREVIOUS => 1000000000
DAY-OF-WEEK ( seconds -- n ) The day of the week as in ISO 8601: 1 is Monday and 7 is Sunday. ;; ALSO DATE 1000000000 DAY-OF-WEEK . PREVIOUS => 7
+DAYS ( seconds n -- seconds' ) Add n days (n may be negative), each of 86400 seconds. Throws -265 outside the years 0 to 9999. ;; ALSO DATE S" 2024-02-28" ISO8601> 2 +DAYS >ISO8601 TYPE PREVIOUS => 2024-03-01T00:00:00Z
+MONTHS ( seconds n -- seconds' ) Add n months (n may be negative); a day that the new month lacks becomes its last day. ;; ALSO DATE S" 2023-01-31" ISO8601> 1 +MONTHS >ISO8601 TYPE PREVIOUS => 2023-02-28T00:00:00Z
LEAP-YEAR? ( year -- flag ) True for a leap year of the Gregorian calendar. ;; ALSO DATE 1900 LEAP-YEAR? . 2000 LEAP-YEAR? . PREVIOUS => 0 -1
DAYS-IN-MONTH ( year month -- n ) The number of days of the month (1 to 12); throws -265 for another month. ;; ALSO DATE 2024 2 DAYS-IN-MONTH . PREVIOUS => 29
[URL]
>PERCENT ( c-addr u -- c-addr' u' ) Percent-encode: every byte except A-Z a-z 0-9 - . _ ~ becomes %XX (upper-case hex), a space is %20. The new text is ALLOCATEd. ;; ALSO URL S" a b&c" >PERCENT TYPE PREVIOUS => a%20b%26c
PERCENT> ( c-addr u -- c-addr' u' ) Decode %XX to bytes, upper or lower case; a + stays a plus. Throws -265 for a % without two hex digits. The new text is ALLOCATEd. ;; ALSO URL S" a%20b%26c" PERCENT> TYPE PREVIOUS => a b&c
URL-SCHEME ( c-addr u -- c-addr' u' ) The scheme of a URL (https), empty when there is none. The answer points into the given text. ;; ALSO URL S" https://example.com/a" URL-SCHEME TYPE PREVIOUS => https
URL-USERINFO ( c-addr u -- c-addr' u' ) The user information before the @ of the authority, empty when there is none.
URL-HOST ( c-addr u -- c-addr' u' ) The host; an IPv6 address keeps its brackets. Throws -265 for a port that is not a number from 0 to 65535 or for a [ without ]. ;; ALSO URL S" https://example.com:8080/a" URL-HOST TYPE PREVIOUS => example.com
URL-PORT ( c-addr u -- n ) The port number, or -1 when the URL has none. ;; ALSO URL S" https://example.com:8080/a" URL-PORT . PREVIOUS => 8080
URL-PATH ( c-addr u -- c-addr' u' ) The path, empty when there is none. ;; ALSO URL S" https://example.com/a/b?x=1" URL-PATH TYPE PREVIOUS => /a/b
URL-QUERY ( c-addr u -- c-addr' u' ) The query after the ?, without the ?. ;; ALSO URL S" https://example.com/a?x=1&y=2#top" URL-QUERY TYPE PREVIOUS => x=1&y=2
URL-FRAGMENT ( c-addr u -- c-addr' u' ) The fragment after the #, without the #. ;; ALSO URL S" https://example.com/a?x=1#top" URL-FRAGMENT TYPE PREVIOUS => top
URL-PARAM ( query-addr query-u name-addr name-u -- value-addr value-u true | false ) The value of the first parameter of a query (a=1&b=2) with that name, as written (use PERCENT> to decode it); a name without = has an empty value. ;; ALSO URL S" a=1&b=2" S" b" URL-PARAM . TYPE PREVIOUS => -1 2
[UUID]
UUID4 ( -- c-addr u ) A random version 4 UUID as 36 lower-case characters (8-4-4-4-12), from the generator of RANDOM, so 7 SEED! makes it repeatable. The new text is ALLOCATEd. ;; ALSO UUID UUID4 NIP . PREVIOUS => 36
